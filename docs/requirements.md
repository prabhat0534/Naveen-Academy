# Naveen Academy Management System

## Project Overview

Naveen Academy Management System is a web application for managing a coaching institute.

## Purpose

The purpose of this website is to help the academy manage students, fees, notes, and other daily work easily.

## Users

- Admin
- Student

## Main Features

- Home Page
- About
- Classes
- Contact
- Student Login
- Admin Login
- Student Management
- Fees Management
- Notes Upload
- Notes Download

## Technology

Frontend:
- React.js
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB
